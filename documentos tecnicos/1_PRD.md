# Product Requirement Document (PRD)
## Portafolio Web Estático - DevOps & MLOps

---

### 1. Visión y Objetivo
[cite_start]Crear un portafolio web estático, de acceso público y gratuito, que sirva como vitrina principal para exhibir mis proyectos y habilidades como Egresado de Ingeniería de Sistemas orientado a DevOps[cite: 7]. El objetivo es presentar la documentación, arquitectura y resultados de mis proyectos sin necesidad de mantener infraestructura activa.

### 2. Público Objetivo
- Reclutadores de TI y Headhunters.
- [cite_start]Líderes Técnicos y evaluadores buscando perfiles con bases sólidas en desarrollo, contenedores y observabilidad[cite: 7, 29].

### 3. Historias de Usuario Principales
- **Como reclutador**, quiero leer tu perfil profesional, ver tus skills claramente listadas y descargar tu CV en PDF.
- **Como líder técnico**, quiero leer el resumen de la arquitectura de tu proyecto de Migración Cloud y tu proyecto de MLOps para evaluar tu nivel teórico y práctico.
- **Como evaluador**, quiero encontrar enlaces directos a tus repositorios de GitHub para revisar la calidad de tu código (Terraform, Dockerfiles, GitHub Actions).

### 4. Métricas de Éxito
- **Performance:** Tiempo de carga inicial ultrarrápido (menor a 1.5 segundos).
- **Mantenibilidad:** Un pipeline CI/CD que actualice la web automáticamente cada vez que agregues un nuevo proyecto al código.
